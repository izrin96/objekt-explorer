# Tasks

Every task ends with its package's checks passing:
- **api checks**: `bun run check --filter=@repo/api`. The package has no build of its own, so `bun run build --filter=web` stands in once web imports the change.
- **web checks**: `bun run check --filter=web` and `bun run build --filter=web`.

The root `.env` is production. Every database or Redis read below is read-only (`PGOPTIONS='-c default_transaction_read_only=on'`). No task writes to production, runs `db:migrate` or commits.
