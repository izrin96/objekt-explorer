# Tasks

Every task ends with `bun run lint`, `bun run typecheck` and `bun run build` passing for the package it touches (`--filter=<package>`). Each slice lands through `incremental-implementation`. Tests cover pure modules only. Before any `.tsx` edit in `apps/web`, load `vercel-react-best-practices`; the `require-react-skill` hook holds the edit until it is loaded. Every new user-facing string is an `m.*` key in `en`, `ko` (statements in 합니다체) and `ja` (full-width ？, 。 where en has `.`), added in the task that first shows it. Nothing writes to production: mutations are verified on the local database, or up to the request boundary ("read-only verified").
